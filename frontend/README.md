# HubMI app

Expo app for reporting city problems on a map and upvoting them.

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go, or press `a` / `i` / `w` for Android, iOS, or web.

The app talks to the deployed API. For a local backend, set `API_BASE_URL` in `src/api/issues.ts` to `http://<your-computer-LAN-IP>:8000`.
